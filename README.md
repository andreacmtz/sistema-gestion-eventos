# sistema-gestion-eventos
Sistema de gestión programado en C para el control financiero y automatización de agendas. 

#funciones
-Registro de eventos validando su disponibilidad para no repetir horarios
-Consulta y lectura de la agenda mediante archivos de texto y binario
-Calculos automaticos necesarios para establecer una buena tarifa final

#conceptos-aplicados
-Estructuras
-Memoria dinamica
-Arreglos
-Validacion de datos de entrada

#Nota
Programa desarrollado para windows, contiene la funcion system('cls'), que no esta disponible en otros sistemas operativos.
